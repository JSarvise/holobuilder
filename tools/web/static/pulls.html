How these ranges are computed

Expected counts come from each banner's own rate table, saved at sync time, with the guaranteed slot of a 10-pull drawn from its own table (9 + 1). The shaded range is where 90 % of players making exactly the same pulls would land. It uses a binomial with the same mean, which is slightly wider than the true spread, so these ranges never overstate how unusual a result is. The rate interval is a 95 % Wilson interval on your own pulls.

Left out of the comparison: ticket and tutorial pulls (no rate roll was made) and banners whose rate table was never saved. They still appear everywhere else on this page.
