# hbuilder — client-side optimizer demo (two WASM engines)

The whole optimizer running in a browser, **no server, no CDN**:

- **Engine 1 — scorer:** the real `src/hbuilder` Python, run **verbatim** on Pyodide
  (CPython→WASM). Scores a team via `score_card_set` — byte-identical to native. ~1 ms/score.
- **Engine 2 — solver:** the leader board as an integer program (nodes + budget +
  connectivity + sockets) solved to the **provable optimum** by `highs.wasm` — the same
  binary a browser loads. Sub-second.

Both engines load from local files. Feasibility study behind it:
[`tools/recon/SOLVER-FEASIBILITY.md`](../../recon/SOLVER-FEASIBILITY.md).

## What's versioned vs generated

Only the hand-written parts are in git — the ~18 MB of WASM binaries and the
account-derived board data are **generated** by `setup.py` (see `.gitignore`):

| in git | generated by `setup.py` |
|---|---|
| `index.html`, `demo.js` (the page, ~14 KB) | `pyodide.*`, `python_stdlib.zip` (Pyodide runtime, ~12 MB) |
| `make_board.py`, `setup.py`, `README.md` | `highs.js`, `highs.wasm` (HiGHS solver, ~3.4 MB) |
| | `hbuilder.zip` (src/hbuilder, 38 stdlib modules) |
| | `data/cards.json`, `data/config.json` |
| | `board.lp`, `board.json` (the current pool-best team's board) |

## Run it

Needs `node`/`npm` on PATH (for the WASM packages) and the proxyenv interpreter (for
`make_board.py`). One-time build, then serve:

```
python tools/web/wasmdemo/setup.py
cd tools/web/wasmdemo
python -m http.server 8791
```

then open **http://127.0.0.1:8791/index.html** . First load pulls ~15 MB of WASM from
disk and boots Pyodide in ~1.5–2 s; after that, scoring is instant and solving is sub-second.

## Honest scope

- The board **node values** are precomputed by `make_board.py` (they come from the same
  scorer); the page runs the scorer live on **team** scoring and the solver live on the
  **board**. A full product would compute the board values in Pyodide too — same code.
- Pyodide (~12 MB) is the zero-port path: `src/hbuilder` is `dependencies=[]` stdlib, so it
  runs unmodified. A lighter native-JS scorer (~200 KB) is the ~1.5–2-month option
  (de-risked by the existing pytest suite as a golden master).
